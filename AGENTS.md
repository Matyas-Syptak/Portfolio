# Project rules

This folder is the only working copy of the professional portfolio.

## Location and repository

- Edit the website only in `C:\Users\matya\Desktop\GitHub\Professional Portfolio - Matyas Syptak`.
- Open this folder in Cursor for future changes.
- The Git remote `origin` is `https://github.com/Matyas-Syptak/Portfolio.git`.
- Do not create another local copy, nested portfolio folder, or GitHub repository for this site.
- Do not change the original Design Portfolio source, its GitHub repository, its Cloudflare deployment, or its public website.

## Publishing

- Review, commit, and push approved changes with GitHub Desktop.
- Fetch and pull before editing so this folder stays synchronized with GitHub.
- The hosting target is GitHub Pages. Do not set up Cloudflare for this project.
- Do not force-push or rewrite history.

## Editing

- Make the requested change only. Leave unrelated pages, styles, scripts, and assets alone.
- Keep the source readable, and comment code so it can be studied later.
- Do not redesign the site or replace its content unless that change was requested.

## Licensing

- Keep the site's existing attribution and license notices.
- Do not add third-party code, fonts, or assets until their licenses permit reuse.
- Record external dependencies and required copyright notices in `THIRD_PARTY_NOTICES.md`.
